## Failure Pattern to Hunt
- The recurring expectancy leak is not lack of stories; it is holding or validating inventory without fresh confirmed demand.
- Synced inventory must be quarantined from true alpha trades.
- Loss control should trigger before a weak, stale position becomes a large loss.
- Feedback must never generate action language that downstream agents could apply to unowned tickers.
- Truncated feedback is failed feedback. If the memory snippet cannot survive storage, the lesson did not land.
