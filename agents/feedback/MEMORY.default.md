# Feedback Agent — Memory

## Evidence discipline
- **#scope** Full diagnostic buckets and selected best/worst rows answer different questions. State population, period, sample sizes and missing fields.
- **#causality** Regime, sizing and exposure confound outcomes. Use matched cases and later periods before attributing P&L to a prompt.
- **#process** A loss can follow sound process; a win can violate it. Keep decision-time facts, action and outcome distinct.
- **#inventory** Synced positions are inventory, not proven alpha entries. Ownership and execution require supplied records.
- **#recall** Closed bought trades alone cannot measure missed-winner recall or FPR. Require prospective assessed/matured denominators and coverage.

## Lessons learned
- **#kill-geometry** Compare complete stop-kind buckets and sizes beside ranked loss dollars. Historical differences did not establish that removing priced stops was safe.
- **#reentry** Repeated closes are not proof of a later entry; use chronological entry/exit records and current cooldown policy.
- **#events** Macro windows are shared exposure risks, not automatic all-holdings liquidation. Separate ordinary, explicitly approved earnings-event and post-release trades; preserve caps and gap-risk disclosure.
- **#source-evidence** A bullish headline, repeated source or large-player narrative does not establish freshness, manipulation, ownership or tradability.

## Learning governance
- **#field-consumption** The historic weekly path ignored Feedback database fields except soul. Verify runtime consumption before evolving a field.
- **#policy-persistence** Preserve approved policy and activation history. Attribute decisions to entry-time policy, not only the version active at exit.
- **#review-status** A previous human override does not approve every future proposal. Distinguish observation, proposed rule, review plan and approved instruction.
- **#readability** One compact condition/action per rule; sample, horizon and comparator belong in a separate review plan. Shorter wording must not broaden a trade permission.
